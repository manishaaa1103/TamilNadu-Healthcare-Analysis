# Tamil Nadu Healthcare Analysis (2013-2017)

## About the Project
This project analyzes healthcare data from Tamil Nadu government hospitals covering the years 2013 to 2017. The dataset was sourced from data.gov.in and includes information on outpatients, inpatients, surgeries, and lab investigations across major government hospitals in Tamil Nadu.

I wanted to understand how healthcare access and hospital performance changed over these 5 years — which hospitals served the most patients, which grew the fastest, and where the gaps are.

## Tools Used
- *Python (Google Colab)* — data cleaning and visualization using Pandas, Matplotlib
- *SQL* — querying and analyzing the data
- *Microsoft Excel* — pivot tables, charts and dashboard
- *Power BI* — interactive 5-page dashboard

## Dataset
- Source: [data.gov.in](https://data.gov.in)
- Coverage: Major Tamil Nadu Government Hospitals
- Years: 2013 to 2017
- Categories: Outpatients, Inpatients, Surgeries, Lab Investigations

## Key Findings
- Rajiv Gandhi Govt. General Hospital, Chennai was the #1 hospital in Outpatients, Inpatients and Lab Investigations
- Total outpatients served across all hospitals: 143 Million
- Total lab investigations conducted: 180 Million
- Thiruvarur Medical College Hospital showed 445% growth in Lab Investigations
- Thanjavur Medical College Hospital showed 227% growth in Surgeries
- Some hospitals showed negative growth indicating possible data gaps or facility changes during this period

## Project Structure
